Import Stock from Spreadsheet

Prepare an Excel/Google Sheet with these column headers in the first row, then Save As → CSV and upload it here:

barcode, name, category, karat, weight_grams, raw_gold_price_per_gram, craftsmanship_per_gram, stamp_charge, location, quantity

  • barcode — the code on the tag (leave blank to auto-generate a JW code)
  • name — required for every row
  • category — ring / necklace / bracelet / earring / chain / pendant / other
  • karat — 18, 21, or 24
  • weight_grams — must be greater than zero, e.g. 5.50
  • raw_gold_price_per_gram — must be greater than zero (EGP/g)
  • craftsmanship_per_gram — zero or more (EGP/g)
  • stamp_charge — zero or more per piece (EGP)
  • location — safe or showcase
  • quantity — a whole number of at least 1

The complete file is validated first. If any row is invalid, nothing is imported and the row errors are shown.
